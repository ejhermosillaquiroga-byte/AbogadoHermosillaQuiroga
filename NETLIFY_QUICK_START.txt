OPCIÓN 1: DRAG & DROP (MÁS FÁCIL)
================================================================================

1. Ir a: https://app.netlify.com
2. Hacer clic en "Add new site"
3. Seleccionar "Deploy manually"
4. Hacer drag & drop de la carpeta "hermosilla-website"
5. ¡LISTO! Tu sitio está en vivo en 30-60 segundos

URL: https://hermosilla-website.netlify.app (o similar)

================================================================================

OPCIÓN 2: CON GITHUB (DESPLIEGUES AUTOMÁTICOS)
================================================================================

1. Subir carpeta a GitHub:
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/usuario/hermosilla-website
   git push -u origin main

2. Ir a: https://app.netlify.com
3. Hacer clic en "Add new site"
4. Seleccionar "Import an existing project"
5. Conectar con GitHub
6. Seleccionar repositorio
7. Hacer clic en "Deploy site"
8. ¡LISTO! Tu sitio está en vivo

URL: https://hermosilla-website.netlify.app (o similar)

Ventaja: Cada push a GitHub = nuevo despliegue automático

================================================================================

OPCIÓN 3: CON NETLIFY CLI (PARA DESARROLLADORES)
================================================================================

1. Instalar: npm install -g netlify-cli
2. Ir a carpeta: cd hermosilla-website
3. Desplegar: netlify deploy --prod
4. Seguir instrucciones
5. ¡LISTO! Tu sitio está en vivo

🚀 PASOS PARA DESPLEGAR EN NETLIFY (3 MINUTOS):

1️⃣  DESCOMPRIMIR
   • Haz clic derecho en "hermosilla-website-complete.zip"
   • Selecciona "Extraer aquí" o "Descomprimir"

2️⃣  ACCEDER A NETLIFY
   • Abre https://app.netlify.com
   • Inicia sesión con tu cuenta

3️⃣  CREAR NUEVO SITIO
   • Haz clic en "Add new site"
   • Selecciona "Deploy manually"

4️⃣  SUBIR LA CARPETA
   • Arrastra la carpeta descomprimida al área de drop
   • O haz clic y selecciona la carpeta

5️⃣  ESPERAR DEPLOYMENT
   • Netlify procesará automáticamente
   • Tu sitio estará en línea en 30-60 segundos
   • Verás una URL: https://[nombre].netlify.app

🔧 OPCIONES ADICIONALES:

CAMBIAR NOMBRE DEL SITIO:
1. Ve a Netlify Dashboard
2. Site settings → Site details
3. Haz clic en "Change site name"
4. Ingresa un nombre (ej: hermosilla-abogado)
5. Guarda

AGREGAR DOMINIO PERSONALIZADO:
1. Site settings → Domain management
2. Haz clic en "Add custom domain"
3. Ingresa tu dominio (ej: hermosilla-quiroga.com)
4. Sigue las instrucciones para apuntar los DNS
5. Netlify generará automáticamente un certificado SSL

USAR GITHUB (RECOMENDADO):
1. Sube la carpeta a GitHub
2. Conecta el repositorio con Netlify
3. Cada cambio que hagas se desplegará automáticamente
